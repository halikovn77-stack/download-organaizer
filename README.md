# Автоматический сортировщик загрузок

Python-программа, которая автоматически сортирует файлы из папки `Downloads` по категориям на основе их расширений. Программа обрабатывает уже существующие файлы при запуске, а затем отслеживает появление новых файлов.

## Возможности

- Сортировка файлов по категориям, заданным в `config.json`.
- Автоматическая обработка новых файлов в папке загрузок.
- Проверка существования имени файла и создание уникального имени при совпадениях (`file_1.ext`, `file_2.ext` и т. д.).
- Пропуск временных файлов загрузки с расширениями `.crdownload` и `.part`.
- Запись событий в консоль и файл журнала `organaizer.log`.
- Предупреждение о файлах, расширения которых нет в правилах сортировки.

## Как это работает

1. При запуске программа загружает правила из `config.json`.
2. Проверяет файлы, уже находящиеся в `~/Downloads`, и сортирует их.
3. Запускает наблюдатель `watchdog`, который отслеживает появление новых файлов.
4. Когда появляется новый файл, программа ждёт 1,5 секунды, проверяет, что файл существует и не является временным, а затем перемещает его в соответствующую категорию.
5. Если файл с таким именем уже есть в целевой папке, программа подбирает свободное имя, чтобы не перезаписать существующий файл.

## Требования

- Python 3.9 или новее.
- Библиотека `watchdog`.

## Установка и запуск

1. Установите Python: https://www.python.org/downloads/
2. Поместите `main.py` и `config.json` в одну папку проекта.
3. Откройте терминал в папке проекта.
4. Установите зависимость:

```bash
python -m pip install watchdog
```

5. Запустите программу:

```bash
python main.py
```

Остановить программу можно сочетанием `Ctrl+C`.

## Настройка категорий

Правила сортировки находятся в `config.json.example`. Прежде чем использовать программу, создайте файл `config.json` и скопируйте в этот файл содержимое `config.json.example`. Ключи JSON — это названия папок-категорий, а значения — списки расширений файлов, которые следует перемещать в эти папки.

Пример текущей конфигурации:

```json
{
  "Изображения": [".jpg", ".jpeg", ".png", ".gif", ".bmp"],
  "Документы": [".pdf", ".docx", ".txt", ".xlsx", ".pptx", ".iso", ".py", ".html", ".pub"],
  "Архивы": [".zip", ".7z", ".rar", ".tar", ".gz"],
  "Видео": [".mp4", ".mkv", ".avi", ".mov"],
  "Музыка": [".mp3", ".wav", ".flac"]
}
```

Можно добавлять категории и расширения, сохраняя корректный JSON-формат. Расширения следует указывать с точкой и в нижнем регистре.

## Важные замечания

- Программа автоматически перемещает файлы. Перед первым запуском проверьте правила в `config.json`.
- Путь к папке загрузок задаётся как `~/Downloads`. Убедитесь, что это правильный путь для вашей операционной системы.
- Файлы с неизвестными расширениями остаются в исходной папке, а в журнал записывается предупреждение.
- Скрытые файлы без расширения, например `.env`, не сортируются по расширению.
- Временные файлы браузера `.crdownload` и `.part` пропускаются.
- Название файла журнала в коде — `organaizer.log` (именно так оно написано в программе).
- В текущей версии программа отслеживает только непосредственное содержимое `Downloads`, без вложенных папок.
